# Ch.6 垂體衰竭：發育性、遺傳性與後天病因（Developmental, Genetic, and Acquired Causes of Pituitary Failure）

> 來源：Williams Textbook of Endocrinology, Ch.6 Pituitary Physiology and Diagnostic Evaluation — 本節涵蓋垂體衰竭之發育/遺傳病因（HESX1、SOX2/3、OTX2、LHX3/4、PROP1、POU1F1、IGSF1、TBX19、PSIS）、後天病因（頭部外傷、SAH、放射線、hypophysitis、empty sella）、hypopituitarism 臨床特徵與各軸篩檢策略總表（Table 6.9 / 6.10）。

---

## 🧬 一、發育異常與遺傳性垂體衰竭

- **發育異常**：垂體發育源自 Rathke's pouch 的中線細胞遷移；中線異常（前腦分裂失敗、胼胝體缺損）與顱顏異常（唇顎裂、basal encephalocele、optic nerve hypoplasia）伴隨程度不等的垂體 dysplasia/aplasia。MRI 特徵：腺體體積縮小、部分/完全 empty sella、垂體柄缺失或截斷、後葉亮點（bright spot）缺失或異位。
- **垂體柄病灶（92 例分析）**：`<u>32%</u>` 為偶然發現；病因約 `<u>15%</u>` 先天性（ectopic posterior pituitary、Rathke's cyst）、`<u>33%</u>` 發炎性（sarcoidosis、histiocytosis、hypophysitis）、`<u>>50%</u>` 腫瘤性（craniopharyngioma、pituitary adenoma、轉移）。原因不明 GHD 病人約 `<u>40%</u>` 有輕度垂體柄缺損影像。

### 遺傳性轉錄因子突變總表

| 基因 | 荷爾蒙缺乏表型 | 特徵性伴隨表現 |
| --- | --- | --- |
| ***HESX1*** | Panhypopituitarism ～ 孤立性 GHD | **Septo-optic dysplasia**（視神經發育不全、胼胝體與 septum pellucidum 缺失）；亦與 **PSIS** 相關 |
| ***SOX2*** | HH + GHD、前葉發育不全 | Septo-optic dysplasia、**anophthalmia/microphthalmia**、前腦缺損 |
| ***SOX3*** | GHD ± gonadotropin/TSH/ACTH 缺乏 | **X-linked** 垂體低下 + 智能障礙；**duplication 與 loss-of-function 表型相似**（劑量敏感） |
| ***OTX2*** | Panhypopituitarism | Anophthalmia/microphthalmia、發展遲緩、癲癇；無法活化 *HESX1* 與 *POU1F1* |
| ***LHX3*** | 多重前葉荷爾蒙缺乏，**唯 ACTH 大致保留** | `<u>頸椎僵硬致頸部旋轉受限</u>` + 感音性聽損 |
| ***LHX4*** | GHD + 身材矮小，變異性 TSH/ACTH 缺乏 | 前葉發育不全、ectopic posterior pituitary、**PSIS**；無法活化 *PROP1*/*POU1F1* |
| ***PITX2*** | 垂體荷爾蒙缺乏 | **Rieger syndrome**：眼、牙齒缺陷 + 突出臍（protuberant umbilicus） |
| ***PROP1*** | **CPHD 最常見遺傳原因**：GH、PRL、TSH + FSH/LH（青春期延遲/缺失、HH、不孕）；**ACTH 缺乏常較晚出現** | Ames dwarf mouse 模型；**自體隱性遺傳**；腺體大小正常或偏小；表型隨突變型與年齡而異 → **需終身持續評估** |
| ***POU1F1* (PIT1)** | GH、PRL、TSH 缺乏 | Snell/Jackson dwarf mouse；**AR（loss-of-function）與 AD（dominant negative）皆有**；成人型可由 **anti-PIT1 自體抗體**引起 |
| ***IGSF1*** | **X-linked 先天性 central hypothyroidism** ± PRL 缺乏、GHD | `<u>睪丸腫大（testicular enlargement）</u>`；垂體 TRH 訊號受損 |
| ***TBX19* (TPIT)** | **早發孤立性 ACTH 缺乏**（congenital neonatal isolated ACTH deficiency 的主要分子病因） | 自體隱性；可伴 POMC 缺乏表型（肥胖、紅髮）；無 *TBX19* 突變之孤立性 ACTH 缺乏合併 CVID → **DAVID syndrome**（*NFKB2*） |
| ***NR5A1* (SF1)** | HH、青春期發育障礙 | XY sex reversal、睪丸發育不全、卵巢功能不全、**腎上腺衰竭** |
| ***NR0B1* (DAX1)** | **X-linked HH**（常輕度、青春期不完全） | **Adrenal hypoplasia congenita** |

- **Pituitary Stalk Interruption Syndrome（PSIS）**三聯徵：`<u>垂體柄變細或中斷</u>` + `<u>前葉發育不全</u>` + `<u>ectopic posterior pituitary</u>`。可為孤立性或合併性荷爾蒙缺乏；相關基因：*HESX1*、*LHX4*、*OTX2*、*SOX3*、*PROKR2*，另有 *GPR161*（SHH 訊號）與 *ARNT2* 之同型合子突變報告。
- 其他症候群性垂體缺乏：CHARGE（*CHD7*）、*PAX6*、septo-optic dysplasia / Kallmann（*PROKR2*、*FGF8*、*FGFR1*）、holoprosencephaly（*SHH*、*GLI2*、*TGIF*）。

> 💡 **記憶法（轉錄因子表型配對）**：「**HESX 隔視中線裂，LHX3 硬頸聽不見；PROP1 缺五最常見，TPIT 孤缺 ACTH 先**」。

## 🏥 二、後天病因（Acquired Disorders）

- Hypopituitarism 盛行率約 `<u>46 / 100,000</u>`；最常見於垂體大腺瘤及其手術/放療，且因常未被認知為其他重大疾病之共病而**被低估**。
- **頭部外傷（TBI）**：成人最常見創傷性病因為**腺瘤切除之神經外科創傷**；TBI meta-analysis（追蹤 ≥3–12 個月）：單軸缺損 `<u>15%</u>`、多軸 `<u>4%</u>`；各軸盛行率 `<u>GH 13% > ACTH 12% > LH/FSH 10% > TSH 4%</u>`（發生率約 7/100,000/年）。**接觸性運動**：退役拳擊手 GHD `<u>45%</u>`；kickboxer GHD 22%、ACTH 缺乏 9%；美式足球員 GHD 19%、性腺低下 9%。兒童（法國前瞻研究 87 名、平均 6.7 歲、TBI 後 5 個月）：GHD 7%、甲狀腺 2%、腎上腺 1%。
- **蜘蛛膜下腔出血（SAH）**：發生率 6–10/100,000，好發 40–60 歲；急性期垂體功能異常約 `<u>46%</u>`，6 個月後降至 `<u>25%</u>`，其中 **GHD 最常見**。急性期評估**聚焦 HPA 軸**（glucocorticoid 攸關存活）；其他軸因可能恢復，宜待生命徵象穩定後再評估。
- **放射線**：損傷程度與**劑量、時間、照射年齡**相關；放射敏感度排序 `<u>GH > gonadotropin > ACTH > TSH</u>`。GHD 可低至 `<u>18 Gy</u>` 即發生；`<u>30–50 Gy</u>` 時 3–5 年內達 `<u>50–100%</u>`。Gonadotropin 缺乏需 `<u>>30 Gy</u>`，但**兒童較低劑量反而造成中樞性性早熟**；`<u>≥40 Gy</u>` 因下視丘損傷引起**高泌乳素血症**。Stereotactic radiosurgery 早期垂體功能異常較分次放療少，但避開下視丘**並未降低長期垂體低下風險** → 曾放療者需**終身定期**垂體功能追蹤。
- **Hypophysitis**：原發性（lymphocytic/autoimmune）vs. 次發性（sarcoidosis、granulomatosis、hemochromatosis、感染、藥物）。**免疫檢查點抑制劑（ICPi）**：anti-CTLA4 約 `<u>3–4%</u>`，合併 anti-PD1 增至 `<u>6–8%</u>`；**男多於女**；典型於 anti-CTLA4 開始後 `<u>8–10 週</u>` 出現；缺損分布 `<u>hypoadrenalism 83% > hypothyroidism 77% > hypogonadism 53%</u>`；**超生理劑量 glucocorticoid 反而使預後惡化**；hypoadrenalism 恢復罕見。
- **Empty sella**：原發性（sellar diaphragm 先天薄弱）— 高達 `<u>50%</u>` 與 benign intracranial hypertension 相關；次發性（腺瘤梗塞、手術/放療後）。多為偶然發現，但垂體組織受壓/萎縮 `<u>>90%</u>` 時通常發生垂體衰竭；約 `<u>10%</u>` 可在受壓組織邊緣長出小型 GH- 或 PRL-secreting adenoma。

## 📋 三、臨床特徵與各軸篩檢策略（Table 6.9 / 6.10）

- 垂體衰竭病人**死亡率過高，主因血管疾病**；診斷年齡、女性、craniopharyngioma 病史為最顯著的死亡決定因子。
- **壓迫下各軸失能順序**：`<u>GH > FSH > LH > TSH > ACTH</u>` — **corticotroph 最抗壓、最晚失能**；lactotroph 反因抑制訊號減少而常**過度分泌**（PRL 缺乏極罕見，僅見於完全破壞或遺傳症候群）。
- **應篩檢對象**：下視丘/垂體腫塊、顱顏發育異常、發炎/肉芽腫疾病、頭頸放療史、頭部外傷、顱底手術史、新發現 empty sella、妊娠相關出血或血壓變化者。垂體大腺瘤/craniopharyngioma/鞍旁病灶者**高達 2/3 有垂體儲備受損**；並應測 PRL（次發性高泌乳素血症常見）。
- 手術減壓後約 `<u>1/3</u>` 功能恢復，但約 `<u>25%</u>` 術後功能進一步喪失 → **每年篩檢**。

| 軸 | 檢測（劑量） | 正常反應切點 |
| --- | --- | --- |
| **ACTH** | Insulin tolerance test（`<u>0.1–0.15 U/kg IV</u>`） | Peak cortisol `<u>>18 μg/dL</u>` 或上升 `<u>≥7 μg/dL</u>` |
|  | Metyrapone（`<u>30 mg/kg PO at 11 PM</u>`） | Peak 11-DOC `<u>≥7 μg/dL</u>`、cortisol `<u>≤7 μg/dL</u>`、ACTH `<u>>75 pg/mL</u>` |
|  | ACTH stimulation（`<u>250 μg IV/IM 或 1 μg IV</u>`） | Peak cortisol `<u>≥20 μg/dL</u>` |
| **TSH** | Free T₄、Total T₃、第三代 TSH；TRH（200–500 μg IV） | Peak TSH ≥2.5 倍，或上升 ≥5–6 mU/L（女）/ ≥2–3 mU/L（男） |
| **PRL** | Serum PRL；TRH 刺激 | PRL ≥2.5 倍 |
| **LH/FSH** | LH/FSH、testosterone（300–900 ng/mL）；GnRH（100 μg IV） | LH 升 2–3 倍或 +10 IU/L；FSH 升 1.5–2 倍或 +2 IU/L |
| **GH** | Insulin tolerance | GH peak `<u>>5 μg/L</u>` |
|  | Glucagon（1–1.5 mg IM） | GH peak `<u>>3 μg/L</u>` |
|  | L-Arginine + GHRH（1–5 μg/kg IV） | GH peak `<u>>5 μg/L</u>` |

### 📊 表格解讀
1. **正常值與臨界值**：ITT 雙軸金標準 — cortisol `<u>>18 μg/dL</u>` 與 GH `<u>>5 μg/L</u>`；glucagon 測 GH 之切點較低（`<u>>3 μg/L</u>`）。
2. **臨床意義與處置走向**：替代治療（Table 6.10）：ACTH 缺乏 → Hydrocortisone `<u>10–20 mg/day</u>` 分次；TSH 缺乏 → L-thyroxine `<u>0.05–0.2 mg/day</u>` 依 T₄ 滴定；男性 → Testosterone enanthate 200 mg IM q2–3wk 或 undecanoate 1000 mg IM q3–6mo；成人 GH → Somatotropin `<u>0.2–1.0 mg SC daily</u>`（兒童 0.02–0.05 mg/kg/day）；Vasopressin 缺乏 → 鼻內 desmopressin 5–20 μg bid 或口服 DDAVP 300–600 μg/day。壓力、手術、懷孕時劑量需重新評估。
3. **生理與病理機轉**：ITT 之低血糖為中樞性壓力刺激，可同時檢驗 HPA 與 GH 軸完整性；metyrapone 阻斷 11β-hydroxylation，正常者 ACTH 驅動 11-DOC 堆積。
4. **易混淆點與考題避坑**：ITT 副作用（盜汗、心悸、顫抖）限制其使用；metyrapone 可誘發 adrenal crisis。**放射線損傷順序（GH 最敏感、TSH 最抗）與壓迫損傷順序（GH 先失、ACTH 最後）都以 GH 為先鋒** — 但 2/3 病人放療後 gonadotropin 缺乏早於 ACTH 缺乏，1/3 相反。

> 💡 **記憶法（失能順序）**：「**Go First（GH 先倒），ACTH 最耐操；PRL 不減反升高**」。

> 📌 **重點 (High-Yield)**：
> - 壓迫性垂體失能順序：`<u>GH > FSH > LH > TSH > ACTH</u>`；放射敏感度：`<u>GH > gonadotropin > ACTH > TSH</u>`。
> - **ICPi hypophysitis**：anti-CTLA4 ± anti-PD1、發病 8–10 週、hypoadrenalism 83% 最常見且**最難恢復**；高劑量類固醇治療反而惡化預後。
> - ***PROP1*** = CPHD 最常見遺傳病因（GH/PRL/TSH + FSH/LH，ACTH 晚發）；***TBX19/TPIT*** = 先天新生兒孤立性 ACTH 缺乏主因。
> - 垂體術後追蹤：`<u>1/3 恢復、25% 進一步喪失</u>` → 每年篩檢各軸 + PRL。
