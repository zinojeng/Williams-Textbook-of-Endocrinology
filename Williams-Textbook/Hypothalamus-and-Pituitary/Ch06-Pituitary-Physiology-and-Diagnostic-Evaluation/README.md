## 🗺️ 本章一句話

> 垂體是接受下視丘門脈訊號、周邊負回饋與腺內旁分泌三層調控的脈衝式指揮中樞，本章沿六大主題（PRL、GH、ACTH、Gonadotropin、TSH 五軸 + 垂體衰竭）逐一鋪陳各軸生理、動態測試切點與替代治療，核心鑑別是「唯一被 dopamine 張力性抑制的 PRL 在垂體柄中斷時不降反升」。

## ⭐ High-Yield 速記（跨節濃縮）

- **五軸中唯一以「抑制」為預設狀態的是 PRL**（TIDA 神經元 dopamine 經 D₂ receptor 張力性抑制）：垂體柄中斷 → 其他軸下降、<u>唯獨 PRL 上升</u>（stalk effect）；stalk effect 幾乎不超過 `<u>2000 mU/L（~100 μg/L）</u>`，超過者指向 prolactinoma。
- **PRL 檢驗兩大陷阱**：<u>hook effect（巨瘤偽低值，1:100 稀釋破解）</u>；<u>macroprolactin（IgG 結合偽高值，PEG 沉澱破解</u>，2089 件高 PRL 檢體中占 22%）。PRL 缺乏唯一臨床表現 = **產後無法泌乳**（Sheehan syndrome 為經典病因）。
- **轉錄因子級聯與缺乏組合的模式辨識**：<u>POU1F1 三缺（GH/PRL/TSH）</u>；<u>PROP1 = CPHD 最常見遺傳原因</u>（三缺 + LH/FSH，**ACTH 缺乏可晚發 → 終身追蹤**）；<u>TBX19（Tpit）= 孤立性 ACTH 缺乏</u>；HESX1 = septo-optic dysplasia；LHX3 = 頸部旋轉受限；IGSF1 = X-linked central hypothyroidism + 睪丸腫大。
- **成人 GHD 診斷**：ITT 為金標準——peak GH `<u><5 μg/L</u>` 異常、`<u><3</u>` 為 severe（禁忌：缺血性心臟病、癲癇）；glucagon 切點 `<u><3</u>`（BMI >30 → `<u><1 μg/L</u>`）；<u>低 IGF-1 + ≥3 個垂體荷爾蒙缺乏 → GHD 機率 >97%，免刺激試驗</u>。**IGF-1 正常不能排除成人 GHD**。
- **GH 替代**：起始 `<u>0.2 / 0.3 / 0.1 mg/day</u>`（年輕男 / 年輕女 / 老年），夜間皮下注射、**以年齡性別配對之 IGF-1 滴定（不以體重計算）**；<u>口服 estrogen 者需增量 50%</u>（肝首渡效應）；活動性惡性腫瘤禁用。
- **GH excess 鑑別核心**：空腹、肝病、控制不良 T1DM、口服 estrogen → GH 升但**保留節律、IGF-1 低/正常**；<u>acromegaly = 自主性分泌 + IGF-1 升高</u>。
- **ACTH 軸切點**：早晨 cortisol `<u><3 μg/dL</u>` 提示缺乏、`<u>>18 μg/dL</u>` 通常正常；ITT/CRH/Cosyntropin 共通及格線 = cortisol `<u>>20 μg/dL（500 nmol/L）</u>`；低劑量（1 μg）與標準（250 μg）cosyntropin 準確度相近，<u>低劑量不通過須以 ITT 或標準劑量確認</u>。
- **次發性（中樞）AI 三個「沒有」**：<u>無高血鉀、無鹽分流失、無色素沉著</u>（鹽皮質素受 RAAS 調控）；替代用 Hydrocortisone 10–20 mg/day 分三次，**不需鹽皮質素**。Cortisol 晝夜節律：峰值 7 AM 前、nadir `<u>11 PM–3 AM</u>`，**Cushing disease 中節律喪失**。
- **GnRH 脈衝式刺激、連續性抑制**——GnRH agonist 去勢治療與脈衝式 GnRH 幫浦生育誘導的共同生理基礎；**kisspeptin（KISS1/KISS1R）為 GnRH 上游關鍵促泌素**，*MKRN3/DLK1* 失能 → 中樞性早熟。
- **HH 生化定義**：性類固醇低下時 LH/FSH「不適當地」偏低或正常；**Kallmann = HH + anosmia**（anosmin 介導 GnRH 神經元遷移障礙）；CDP vs 先天 HH：<u>隱睪或 micropenis 支持先天 HH</u>、身高相對父母偏矮支持 CDP，`<u>>14 歲</u>` 青春期未啟動須評估。
- **Central hypothyroidism**：僅約 <u>1/3 病人 basal TSH 偏低</u> → 診斷靠 <u>低 T₄ + 不相稱之 TSH（低/正常/輕度升高）</u>；治療以 L-thyroxine 滴定至 <u>mid-normal free T₄</u>、**不可用 TSH 導引劑量**；<u>疑 ACTH 缺乏者須先評估並治療腎上腺軸再補甲狀腺素</u>（避免 adrenal crisis）。
- **高 TSH + 高 T₄ 鑑別**：TSH-secreting adenoma（<u>TRH 無反應</u>）vs thyroid hormone resistance（<u>TRH 有反應</u>）。
- **壓迫性垂體失能順序**：`<u>GH > FSH > LH > TSH > ACTH</u>`（corticotroph 最耐壓）；放射敏感度：`<u>GH > gonadotropin > ACTH > TSH</u>`（GHD 可低至 `<u>18 Gy</u>` 即發生；30–50 Gy 於 3–5 年內達 50–100%）——兩序列皆以 **GH 為先鋒**。
- **ICPi hypophysitis**：anti-CTLA4 約 3–4%（合併 anti-PD1 增至 6–8%）、典型於開始後 `<u>8–10 週</u>` 出現；缺損分布 <u>hypoadrenalism 83%</u> > hypothyroidism 77% > hypogonadism 53%；**超生理劑量 glucocorticoid 反而使預後惡化**、hypoadrenalism 恢復罕見。
- **垂體術後追蹤**：手術減壓後約 <u>1/3 功能恢復、25% 進一步喪失</u> → **每年篩檢各軸 + PRL**；曾放療者需**終身**定期垂體功能追蹤。
