# Ch.7 垂體腫塊效應、評估與影像（Pituitary Mass Effects, Evaluation, and Imaging）

> 來源：Williams Textbook of Endocrinology, Ch.7 Pituitary Adenomas and Masses — 本節涵蓋擴張性鞍區腫塊的局部效應（TABLE 7.1）、病人評估流程與荷爾蒙篩檢（TABLE 7.2）、MRI/CT 影像判讀，以及 neuroophthalmologic 視野評估。

---

## 🧠 一、Pituitary Mass 局部效應（Mass Effects）

- 擴張中的鞍內腫塊會壓迫正常垂體組織，並經**骨質侵蝕與重塑（bony erosion and remodeling）**改變蝶鞍大小形狀；此過程緩慢，歷經**數年至數十年**。
- **鞍頂（dorsal sellar roof）阻力最小**，故腫瘤最易向上（suprasellar）擴張。
- **視交叉（optic chiasm）壓迫**：由下方施壓 → 先影響**顳側視野（temporal fields）**，<u>由上方開始</u>，逐步擴及整個顳側視野；持續進展可波及鼻側視野，終致**失明（blindness）**；長期壓迫造成 **optic disc atrophy（視神經盤萎縮）**。
- **海綿竇（cavernous sinus）侵犯**：可影響 **CN III、IV、VI 及 CN V 的眼支（ophthalmic）與上頜支（maxillary）**，但即使侵入也**罕見**造成神經症狀；腺瘤常包繞 internal carotid artery 但**血管併發症罕見**。可出現不等程度的 diplopia、ptosis、ophthalmoplegia、顏面感覺減退。
  - 對比：**腺瘤出血或梗塞（hemorrhage/infarction）之急性打擊**較常影響竇內神經。
- **向下擴張**進入 sphenoid sinus = 骨性鞍底已被侵蝕；侵襲性腺瘤可侵犯顎部（roof of palate）造成鼻咽阻塞、感染與 **CSF 滲漏**。
- **顳葉/額葉侵犯（少見）**：uncinate seizures、人格障礙、嗅覺喪失（anosmia）。
- **頭痛（headache）**：即使無 suprasellar extension，microadenoma 在密閉蝶鞍內造成的小幅**鞍內壓（intrasellar pressure）**變化即足以牽扯 dural plate 引發頭痛。
  - DA 或 SRL 藥物治療小型功能腺瘤常伴隨頭痛顯著改善；microadenoma 術後回顧研究中，頭痛在 NFA 病人 <u>90%</u>、功能性腺瘤病人 <u>56%</u> 解除或消失。
- **垂體低下（hypopituitarism）**：49 例 transsphenoidal 切除研究中，伴垂體功能衰竭者平均鞍內壓升高 <u>2–3 倍</u>；頭痛盛行率與 PRL 上升皆與鞍內壓正相關 → 提示**門脈輸送下視丘荷爾蒙受阻**；手術減壓後部分垂體功能可恢復。
- **垂體柄壓迫（stalk compression）**：門脈血管受壓 → 垂體失去下視丘 trophic hormone 供應 → 垂體衰竭；同時 **dopamine 無法到達前葉 → <u>高泌乳素血症（hyperprolactinemia）</u> 併其他 trophic hormone 衰竭**。

### 📋 TABLE 7.1 擴張性垂體/鞍旁/下視丘腫塊之局部效應

| 受累結構 | 臨床效應 |
| --- | --- |
| **Pituitary** | 生長遲滯、成人 hyposomatotropism、hypogonadism、hypothyroidism、hypoadrenalism |
| **Optic tract** | 紅色感知喪失、**bitemporal hemianopia**、上顳側視野缺損、scotoma、失明 |
| **Hypothalamus** | 體溫失調、肥胖、**AVP deficiency**；口渴、睡眠、食慾、行為與自律神經失調 |
| **Cavernous sinus** | Ptosis、diplopia、ophthalmoplegia、顏面麻木 |
| **Temporal lobe** | Uncinate seizures |
| **Frontal lobe** | 人格障礙、anosmia |
| **Central** | 頭痛、水腦、精神病、失智、laughing seizures |
| **Neuro-ophthalmologic** | 視野缺損：bitemporal hemianopia（<u>50%</u>）、amaurosis with hemianopia（<u>12%</u>）、對側或單眼 hemianopia（<u>7%</u>）；scotomas、acuity 下降、瞳孔異常（afferent defect）、optic atrophy、CN palsy、nystagmus、postfixation blindness |

### 📊 表格解讀

1. **正常值與臨界值**：視野缺損型態分布——bitemporal hemianopia <u>50%</u> 最常見；amaurosis with hemianopia <u>12%</u>；對側/單眼 hemianopia <u>7%</u>。
2. **臨床意義與處置走向**：受累結構→症狀可反推腫瘤擴張方向（上=視交叉、旁=海綿竇、下=蝶竇）；出現視野缺損或壓迫性垂體低下即進入手術減壓的適應症討論。
3. **生理與病理機轉**：來自鼻側視網膜的纖維在 chiasm 交叉（decussation），下方纖維先被由下而上的腫塊壓迫 → 顳上視野最早受損；stalk 受壓則「dopamine 斷線」→ PRL 升、其他軸降。
4. **易混淆點與考題避坑**：海綿竇「侵犯常見、神經症狀罕見」——影像看到侵犯≠必有 CN palsy；急性 CN 症狀反而要想到**出血/梗塞（apoplexy）**。Stalk effect 的 PRL 上升是**輕中度**，勿誤判為 prolactinoma。

## 🔍 二、病人評估流程（Approach to the Patient）

- **多數垂體腫塊是腺瘤**：transsphenoidal 手術系列 <u>91%</u>（1120 例）；MRI 系列 <u>82%</u>（2598 例）。最常見非腺瘤病灶：**Rathke's cleft cyst、craniopharyngioma、meningioma**——其中 Rathke's cyst 佔此類腫塊高達 <u>40%</u>。
- **生理性垂體腫大**須先排除：懷孕（lactotroph hyperplasia）；長期**原發性甲狀腺/性腺/腎上腺衰竭**造成 thyrotroph/gonadotroph/corticotroph hyperplasia；異位 **GHRH/CRH** 分泌（肺、胰 NET、hypothalamic gangliocytoma）。
- **偶發瘤（incidentaloma）流行病學**：屍檢 <u>≤20%</u> 帶沉默腺瘤；正常成人 MRI 約 <u>10%</u> 有 microadenoma 樣異常。
- **評估兩問**：(1) 是否有荷爾蒙功能？(2) 是否有（或將有）局部壓迫效應？
- **內分泌檢測應在就診時即執行**（Table 7.2），因荷爾蒙異常的臨床表現潛伏（insidious）可達數年至數十年。

### 📋 TABLE 7.2 荷爾蒙分泌性腺瘤之實驗室診斷

| 腺瘤 | 檢測 | 需進一步評估之結果 |
| --- | --- | --- |
| **Prolactinoma** | 血清 PRL | PRL 上升 |
| **Acromegaly** | 血清 IGF1 | 年齡校正 IGF1 上升 |
|  | OGTT（75 g glucose），於 0、30、60 分測 GH | 超敏感分析下 GH <u>>0.4 μg/L</u> |
| **Cushing disease** | 24 小時 UFC | 至少 <u>2 次</u>檢測 UFC 上升 |
|  | 午夜唾液 cortisol | 游離唾液 cortisol 上升 |
|  | 21:00 給 dexamethasone <u>1 mg</u>，08:00 測血漿 cortisol | 未能抑制至 <u><1.8 μg/dL</u> |
|  | 血清 ACTH | 低 ACTH → 腎上腺腺瘤；極高 → 想到異位 ACTH |
| **TSH-secreting tumor** | 血清 TSH + Free T4 | T4 正常或升高**且 TSH 可測得（unsuppressed）** |

### 📊 表格解讀

1. **正常值與臨界值**：PRL <u>>200 ng/mL</u> 強烈提示 micro-/macroprolactinoma；<u>>500 ng/mL</u>（非懷孕）為 prolactinoma 之 **pathognomonic**；OGTT 後 GH <u>>0.4 μg/L</u>、1-mg DST cortisol <u>≥1.8 μg/dL</u> 為篩檢切點。
2. **臨床意義與處置走向**：無高分泌症候群臨床表現時做**成本效益篩檢**即可；偶發無症狀腫塊中功能性腺瘤的整體發生率低。鞍旁腫塊來源不明時，**手術取得組織病理**可能是確診最佳途徑（但須衡量 biopsy/手術利弊）。
3. **生理與病理機轉**：輕中度 PRL 上升可為 microprolactinoma **或** stalk 阻斷（常見於 NFA macroadenoma）；risperidone 等抗精神病藥也可顯著升高 PRL——這是 >500 ng/mL 才算 pathognomonic 的原因。
4. **易混淆點與考題避坑**：**TSH-oma 的關鍵是「T4 高 + TSH 未被抑制」**（inappropriately measurable TSH），不是 TSH 絕對值高低。PRL 200–500 ng/mL 灰色地帶：macroadenoma + 中度 PRL 上升 → 先想 **stalk effect**，勿貿然當 prolactinoma 治療。

> 💡 **記憶法（PRL 判讀口訣）**：「**二百起疑五百斷，中間灰帶想柄斷（stalk）**」——PRL >200 起疑 prolactinoma，>500 幾可確診，中間須排除 stalk interruption 與藥物。

## 🖥️ 三、影像判讀（Imaging）

- **MRI 為首選**：軟組織解析度最佳。懷疑鞍區腫塊時應做**垂體專屬 MRI**（routine brain MRI 切面太寬，易漏小腫塊）。
- **技術要求**：高解析 **T1-weighted** coronal + sagittal，gadolinium 顯影**前後**皆照；切片厚度 <u><3 mm</u>（達成 1 mm pixel）；必要時加 **T2**（診斷高訊號之出血特別有用）。
- **正常判讀要點**：
  - 腺體可呈 concave、convex 或 flat。
  - **後葉亮點（posterior bright spot）**：T1 高訊號，<u>隨年齡下降</u>；**AVP deficiency 及多數後葉病灶時消失**。
  - 青春期、懷孕、產後可有生理性腫大；**懷孕時腺體不應超過 <u>10–12 mm</u>、stalk 直徑不應超過 <u>4 mm</u>**。
  - **Stalk 增厚**：想到 hypophysitis、granuloma、germinoma 或 chordoma。
- **Microadenoma**：gadolinium 後（頭幾分鐘之 thin section 序列）相對正常腺體**低訊號（hypodense）**；可造成腺體不對稱或 stalk 偏移。
- **Macroadenoma**：血管較豐富 → gadolinium 攝取較高；可重塑骨性鞍窩、向上使視神經「披掛（draping）」於腫塊上；**可見組織包繞 carotid artery = 確認海綿竇侵犯**。
- **鑑別線索**：看得到**與腫塊分離的正常垂體** → 腫塊可能非垂體源。次要特徵（鈣化、出血、質地、suprasellar 侵犯）輔助判讀，最終常仍需病理確認。動脈瘤術前以 MRI/MR angiography 確認。**腎功能不全時 gadolinium 可能禁忌**。
- **CT 角色**：看**骨質結構**（鞍底、clinoid）與骨侵犯；辨識 **craniopharyngioma、meningioma 的鈣化**（腺瘤罕見鈣化）；適用於出血性病灶、轉移、chordoma 與鈣化評估。
- **受體影像（Receptor Imaging）**：prolactinoma 表現 **D2R** → 可用 ¹²³I-iodobenzamine SPECT；radiolabeled indium-pentetreotide 特異性有限（腺瘤 SST 表現異質、正常垂體也有攝取），但對**異位 ACTH 腺瘤**定位可能有幫助；**¹¹C-methionine PET-CT** 有助 equivocal prolactinoma 之手術決策。

## 👁️ 四、Neuroophthalmologic 評估

- **解剖關鍵**：optic chiasm 與 diaphragma sellae 之間有 <u>10 mm</u> 後傾間隙（Fig. 7.6）→ 需**相當程度的 suprasellar 擴張**才會影響視覺。
- 鼻側視網膜纖維於 chiasm **交叉（decussate）**；顳側纖維走同側；上/下視網膜纖維在 chiasm 對應區域分層。
- **視覺損害的可逆性與壓迫急性度成反比**；大腫塊長期壓迫幾乎必然預後不佳。
- **現況**：影像與檢驗普及後，以視覺症狀為初診表現者已 <u><10%</u>（過去幾乎全部以視力喪失表現）；多數為偶發之 NFA。
- **典型缺損**：下方交叉纖維先受壓 → **bitemporal 視野缺損、以<u>上顳側（superior fields）</u>最早**（Fig. 7.7）；進展可波及鼻側視野與 optic atrophy。
  - **垂體性缺損的特徵：以垂直中線（vertical midline）為界**——與其他原因的 bitemporal 缺損之鑑別點。
  - 即使視野缺損明顯，**殘存視野的視力（acuity）通常正常**；腫塊向前延伸才可能損及中心視力。
- **術前評估項目**：自動定量視野檢查（automated quantitative perimetry）、visual evoked potentials、afferent pupillary defect、視神經盤外觀；**OCT（optic coherence tomography）** 評估 retinal fiber layer 厚度/ganglion cell layer 受損 → 可預測**術後視力恢復潛力**。

> 💡 **記憶法（視野進展口訣）**：「**由下往上壓，顳上先開花；越壓越全顳，再犯鼻側家**」——下方纖維先受壓 → 上顳側視野先缺損 → 全顳側 → 鼻側。

> 📌 **重點 (High-Yield)**：
> - **Bitemporal hemianopia（superior 為先）+ 以垂直中線為界** = 垂體腫塊壓迫視交叉的招牌視野表現（TABLE 7.1：佔視野缺損 <u>50%</u>）。
> - **懷孕垂體切點**：腺體 <u>≤10–12 mm</u>、stalk <u>≤4 mm</u>；超過即異常。
> - **後葉亮點消失** = AVP deficiency 的影像線索。
> - 視力受損能否恢復看**壓迫急性度**與 **OCT 的 retinal fiber layer**；chiasm 距 diaphragma sellae <u>10 mm</u>，故小腫塊不會有視野缺損——「microadenoma + 視野缺損」要重新想診斷。
