## 🗺️ 本章一句話

> 鞍區腫塊絕大多數是良性垂體腺瘤：先問「有無荷爾蒙功能、有無壓迫效應」，以 MRI＋視野＋內分泌檢測評估，再依腺瘤類型選擇治療三武器（手術／放射／藥物）——Prolactinoma 藥物優先（DA）、其餘功能瘤與壓迫性 NFA 手術優先；同時熟記鞍旁腫塊、垂體炎與 apoplexy 的鑑別陷阱。

## ⭐ High-Yield 速記（跨節濃縮）

- **鞍區腫塊 = 先想腺瘤**：transsphenoidal 手術系列 <u>91%</u>、MRI 系列 <u>82%</u> 為腺瘤；最常見非腺瘤病灶為 **Rathke's cleft cyst、craniopharyngioma、meningioma**。屍檢 <u>≤20%</u>、正常成人 MRI 約 <u>10%</u> 有沉默微腺瘤——「看到」不等於「要處理」。
- **視野缺損招牌**：由下往上壓 → <u>上顳側視野最早受損</u> → **bitemporal hemianopia（佔視野缺損 50%）**、以<u>垂直中線</u>為界；chiasm 距 diaphragma sellae <u>10 mm</u>，故「microadenoma + 視野缺損」要重想診斷。
- **PRL 判讀階梯**：stalk effect 通常 <u>≤100 ng/mL</u>、藥物性通常 <u>不超過 150 ng/mL</u>、<u>>200 ng/mL</u> 起疑 prolactinoma、<u>>500 ng/mL</u>（非懷孕）為 pathognomonic。兩大檢驗陷阱：**hook effect（血清稀釋重測）** 與 **macroprolactin（PEG 沉澱）**。
- **治療三武器順位**：Prolactinoma → **藥物優先（cabergoline 0.25 mg 每週 1–2 次起始，PRL 正常化 <u>83%</u> vs bromocriptine 52%）**；GH 瘤、TSH 瘤、**所有 ACTH 瘤**、壓迫性 NFA → **手術優先**；放射多為輔助——止長 NFA <u>>90%</u> 但 10 年 <u>80%</u> 出現垂體軸缺損、SRS 後垂體衰竭中位 <u>5 年</u>。
- **經蝶手術必背數字**：永久併發症（AVP deficiency、hypopituitarism、SIAD）<u>≤10%</u>、死亡率 <u><1%</u>；分泌性腺瘤術後復發最強預測因子 = <u>術後基礎荷爾蒙值</u>。**術後三相 AVP deficiency**：多尿 → <u>days 6–11</u> interphase（藏 SIADH 低血鈉）→ 多尿可復發。
- **AVP 缺乏（尿崩）在垂體腺瘤極罕見**——一旦出現，優先想**顱咽管瘤、hypophysitis、germinoma、LCH、轉移**（轉移瘤好發<u>後葉</u>，乳癌 <u>37.2%</u> 最多）。柄增厚鑑別看年齡：成人想 hypophysitis/轉移，兒童想 germinoma/LCH。
- **Craniopharyngioma 兩型突變**：Adamantinomatous = <u>*CTNNB1*（β-catenin）</u>、較易復發；Papillary = <u>*BRAF* V600E</u>、可標靶（BRAF/MEK 抑制劑）；<u>AVP 缺乏常為最早表現</u>、CT 見鈣化。腦膜瘤 MRI 招牌：<u>T1、T2 皆等訊號</u>；鞍旁腫塊**術前必排除動脈瘤**。
- **垂體炎考點**：Lymphocytic 型好發<u>懷孕/周產期</u>、<u>56% 先中樞性腎上腺不全</u>（與腺瘤壓迫先掉 GH/性腺不同）；IgG4 型 = <u>≥10 IgG4+ 漿細胞/HPF</u>、男多、GC 反應佳；**ICI 垂體炎**（ipilimumab 8–10%）中位發病 <u>4 個月</u>、<u>84%</u> 續發性腎上腺不全、輕中度僅補充劑量 GC 不必停免疫治療、內分泌缺損多不可逆。
- **Pituitary apoplexy = 內分泌急症**：劇烈頭痛 + 眼肌麻痺/視野缺損；急救 = **壓力劑量糖皮質素 + 視野受損即刻經蝶減壓**（視力恢復與延遲時間成反比）。**Apoplexy 與 Sheehan 是少數「不會」高 PRL 的垂體病灶**；Sheehan 招牌 = <u>產後無法哺乳 + 無月經</u>。
- **Driver 突變口訣「G 生長、U 皮質」**：<u>*GNAS*（Arg201/Gln227）見於 up to 40% GH 腺瘤</u>；<u>*USP8* 見於 up to 60% corticotroph 腺瘤</u>；senescence 是腺瘤幾乎恆為良性的煞車；**惡性垂體瘤診斷要件 = <u>顱外轉移</u>**（不是 Ki-67）；aggressive adenoma：Knosp 3–4 + <u>6 個月生長 >20% 且 ≥2 mm</u> + Ki-67 <u>>3%</u>，救援藥物 = **Temozolomide**（<u>3 個療程</u>後再評估）。
- **Prolactinoma 懷孕鐵則**：<u>hCG 陽性即停 DA</u>；孕期擴張風險 macro <u>~50%</u> vs micro <u><5%</u>（macro 孕前先縮瘤/手術）；孕中追蹤靠視野**不靠 PRL**、MRI 不打 gadolinium。停藥條件 = <u>治療 ≥2 年 + 無鞍旁侵犯</u>；低劑量 cabergoline（<u>≤3 mg/週</u>）無臨床瓣膜病變疑慮。
- **NFA 不是「觀察就好」**：GH 缺乏可達 <u>85%</u>、hypogonadism <u>75%</u>——所有 NFA 皆須驗垂體軸；incidentaloma 觀察下增大率 macro <u>23%</u> vs micro <u>10%</u>；**silent corticotroph adenoma 是最兇的 NFA**（TPIT、男:女 2:1、易復發）。FSH 瘤 = <u>高 FSH＋低 LH</u>＋雙側多發卵巢囊腫（ovarian hyperstimulation），**禁用 GnRH agonist、手術是唯一確定性治療**。
- **Acromegaly 確診公式**：<u>75-g OGTT nadir GH 不能壓至 <0.4 μg/L（超敏）/<1.0 μg/L（標準）</u> + <u>年齡校正 IGF1 升高</u>；隨機 GH 不可診斷。診斷時**所有患者做篩檢大腸鏡**（息肉 32%、RR 6.21）；死亡率正常化門檻 = <u>GH <2.5 μg/L + IGF1 正常化</u>。**Pegvisomant 只看 IGF1 追蹤（GH 反而上升）+ 每 6 個月肝功能**；pasireotide 高血糖達 <u>57%</u>；ectopic GHRH（carcinoid 等）→ 切來源腫瘤、不開垂體（病理為 hyperplasia、reticulin 保留）。
- **Cushing disease**：1-mg DST 無法壓至 <u><1.8 μg/dL</u> 支持診斷；標準 <u>1.5T MRI 僅偵測 50%</u> 腺瘤 → MRI 陰性不能排除，靠 **IPSS** 側化；手術緩解 micro <u>~80%</u> / macro <u>~60%</u>、復發 <u>5–35%</u> 可晚至 5–10 年；雙側腎上腺切除後不追蹤 → **Nelson syndrome**。
- **TSH-oma vs RTH**：同為「T4/T3 高＋TSH 不受抑制」，鑑別靠 <u>α-subunit/TSH 莫耳比 >1</u>（約 85%）、TRH 試驗 TSH <u>鈍化</u>、MRI 有無腫塊；<u>antithyroid drugs 與 RAI 禁用</u>（解除負回饋反使腫瘤更侵襲）；「垂體腫塊＋TSH 高＋<u>T4 低</u>」= 原發性甲低之垂體增生——先補 levothyroxine、勿手術。
