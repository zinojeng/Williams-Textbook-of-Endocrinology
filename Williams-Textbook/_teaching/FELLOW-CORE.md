## 二、先修鏈（prerequisite chains）

出題與授課時，鏈上游概念須先覆蓋；箭頭右端章節可直接引用左端概念不再重教，但適合作為題幹回收素材。

**(a) ACTH 軸 → 腎上腺功能不全 → ICI**
`Ch6/04 ACTH 生理與 cortisol 切點` → `Ch13/02 原發 AI（Addison）` → `原發 vs 次發鑑別（RAAS intact、無 hyperpigmentation）` → `Ch6/07 + Ch13/Case + Ch44/00 ICI 相關 ACTH 缺損（hypophysitis／孤立 ACTH 缺損）`

**(b) Cortisol 過多的診斷鏈**
`Ch6/04 HPA 負回饋` → `Ch13/03 Cushing 篩檢三 test（1-mg DST 1.8）` → `ACTH 分岔（<10 vs >20）` → `垂體 vs 異位：IPSS（IPS:P ≥2／≥3）` → `Ch7/09 Cushing disease TSS（micro ~80%／macro ~60% 緩解）`

**(c) 垂體功能判定 → 功能性腺瘤 → 家族性症候群**
`Ch6 五軸生理與動態試驗原則` → `Ch7 功能性腺瘤確診（acromegaly OGTT/IGF-1；TSHoma TRH/α-subunit；prolactinoma PRL 階梯）` → `Ch42 familial pituitary tumors（MEN1、MEN4、Carney complex、FIPA/AIP）`

**(d) 腎上腺分帶 → 遺傳性腫瘤 → PPGL（待 ingest）**
`Ch13/01 三分帶與 steroidogenesis（PNMT 依賴皮質 cortisol）` → `Ch42/03 MEN2 pheo 篩檢（11 歲起）與 VHL/NF1` → `Ch14 PPGL（never-biopsy、先 α 後 β、SDHx）＝目前最大未 ingest 缺口`

**(e) β-cell 生理 → 單基因糖尿病 → 低血糖鑑別 → 科技與重症管理**
`β-cell K-ATP channel 與 insulin–C-peptide 關係（Ch32，未 ingest；FellowCamp 已覆蓋）` → `Ch37 monogenic DM（K-ATP neonatal DM → SU）` → `Ch43/02 insulinoma／內源 vs 外源低血糖` → `Ch44/00 ICI-DM（猛爆 DKA、C-peptide 測不到）` → `Ch36 CGM/AID 管理 + Ch48/04 ICU 血糖 140–180`

**(f) 自體免疫機轉橫串**
`Ch44/00 central（AIRE）/peripheral（Treg）tolerance 與 checkpoint` → `Ch44/01–03 APS-I／APS-II／IPEX` → `ICI 毒性家族：ICI-hypophysitis（Ch6/07、Ch7/04）＋ ICI 次發 AI（Ch13/Case）＋ ICI-DM（Ch44 錨點）＋ ICI thyroiditis（甲狀腺章，未 ingest）`
